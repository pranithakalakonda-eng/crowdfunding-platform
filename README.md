# KindFund — Crowdfunding Platform Prototype

KindFund is a simple, front-end crowdfunding platform prototype that demonstrates how people can discover campaigns, explore categories, search for causes, create a campaign, and make a demo contribution.

> **Note:** This is a prototype for demonstration and learning purposes. Contributions are simulated; the project does not process real payments or provide a production backend.

## Features

- Browse crowdfunding campaign cards
- Search campaigns by keyword
- Filter campaigns by category
- Open a form to create a campaign
- Try a demo contribution flow
- Responsive layout for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
KindFund/
├── index.html

```

The interface, styling, and JavaScript are contained in `index.html`.

## How to Run the Project

### Option 1: Open in a browser

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The prototype opens in your default web browser.

### Option 2: Run with Visual Studio Code

1. Open Visual Studio Code.
2. Select **File → Open Folder** and choose the project folder.
3. Open `index.html`.
4. If you have the **Live Server** extension installed, right-click `index.html` and select **Open with Live Server**.
5. Your browser will open the running prototype. Save changes in VS Code and refresh the page if needed.

## How to Use

1. Browse the sample campaigns on the home page.
2. Use the search box to find campaigns.
3. Select a category to filter the displayed campaigns.
4. Use the create-campaign option to try the campaign form.
5. Use a campaign's contribution option to test the demo contribution flow.

The displayed campaigns and contributions are for demonstration only. Data may not persist after refreshing or closing the page.

## Limitations

- No real payment gateway is connected.
- No backend or database is configured.
- Authentication and user accounts are not implemented.
- Campaign and contribution data are not guaranteed to persist.
